# SPEC-002 — Mind + Overview

**Status:** planned  
**Branch:** `feat/spec-002-mind`  
**Depends:** SPEC-001 (needs hardened persistence)  
**Days:** 3  

## Goal

One command answers "what should I do next?" offline, no LLM, no server. A derived **Mind** snapshot fuses board+sprint+memory+context+git history into 4 panels.

## Context

Vision §11.2 / §14.2 / §15.1. Solo devs lose 12-15 switches/day ×23 min recovery = 4.5 hrs/day. Standup board walk = 30 min/week. `monitor.rs` insights + `orchestrate.rs: analyze_board` already compute blockers/stale/bottlenecks, but human must run 3 commands to see.

Mind is **derived, not source of truth**: regenerated by `barkcli mind sync`, written to `.board/mind/snapshot.json` + `digest.md` (human markdown). `barkcli overview` renders it. No daemon required.

## Requirements

### R1 — Model `MindSnapshot`

NEW `barkcli-core/src/mind/mod.rs` + `snapshot.rs` + `digest.rs`

```rust
pub struct MindSnapshot {
  pub board_name: String,
  pub generated_at: DateTime<Utc>,
  pub stats: BoardStats, // total, by_column {todo,doing,review,done}, by_priority, by_label
  pub active_sprint: Option<Sprint>,
  pub blockers: Vec<Blocker>, // { card_id, title, blocked_by: Vec<String>, ty: LinkType }
  pub stale_cards: Vec<StaleCard>, // { id, title, column, days_stale }
  pub next_actions: Vec<String>, // e.g. "run barkcli plan auth-middleware --tasks", "dispatch 3 pending"
  pub recent_history: Vec<HistoryEntry>, // last 10
  pub recent_sessions: Vec<SessionEntry>, // last 10
  pub top_memories: Vec<MemoryEntry>, // store.search("project conventions", 3)
  pub velocity: Option<VelocityReport>, // from agent/capacity.rs if sprint exists
}

pub struct Blocker { pub card_id: String, pub title: String, pub blocked_by: Vec<String> }
pub struct StaleCard { pub id: String, pub title: String, pub column: String, pub days: i64 }
```

### R2 — `barkcli mind sync` + `show`

NEW `barkcli-core/src/commands/mind.rs`

- `barkcli mind sync [--board <n>] [--quiet]`:
  1. Loads: Board (`board_file::read_board`), TaskQueue (`.board/tasks/*.json`), AgentRegistry (`.board/agents/registry.json`), MemoryStore (`.board/memory/*.json`), BoardContext (`.board/context/*.json`), Sprints (`.board/sprints/*.json`), History (`.board/history/*.jsonl`), Sessions (`.board/sessions/*.jsonl`)
  2. Computes: stats, blockers = cards where `links ty BlockedBy` OR `blocked_by` non-empty, stale = `updated_at < now -7d && column != done`, next_actions heuristics:
     - if `todo` cards with `checklist.is_empty` → "barkcli plan <id>"
     - if `tasks pending >0` → "barkcli dispatch"
     - if `review` has cards → "barkcli review --all"
     - else "barkcli intake '...'"
  3. Writes: `.board/mind/snapshot.json` (pretty) + `.board/mind/digest.md` (template, see R5)
  4. No network, no LLM. <100 ms for 100 cards + 500 memories (TF-IDF only on alt path).

- `barkcli mind show [--board <n>]` → prints `digest.md` or renders snapshot pretty.

### R3 — `barkcli overview`

NEW `barkcli-core/src/commands/overview.rs` (or extend `status.rs`)

- Alias: `barkcli status --mind` also works.
- Calls `mind::snapshot::build(board_name)` and renders 4 panels boxed via `comfy-table`:

```
Board: my-project — 23 cards (todo:8 doing:4 review:2 done:9)
Sprint: Sprint 2 — 8/12 done ████████░░ velocity 11 pts
Blockers: 2  • payment-hook blocked by jwt-validation (doing, 9d stale)
Stale: 1  • auth-middleware (doing, 9d)
Next: barkcli plan auth-middleware --tasks → dispatch
Recent: [history 5] feat: add login → doing (2h ago) | [memory] use axum for HTTP
```

- Offline: works with `BARKCLI_API_KEY=""`.
