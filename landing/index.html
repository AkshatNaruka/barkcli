Questions & answers

Is this really one-time? No subscription?
Yes. Pay once, use forever. Your tasks live in your git repo — they're YAML files. Even if you stop using board, your data is readable, diffable, and completely yours. No vendor lock-in, ever.
How is this different from Linear or Jira?
No cloud dependency. No per-user pricing. Your tasks are stored as plain YAML in your git repo — you can cat, grep, and git diff them. Board is a single binary that works offline — no servers, no databases.
What happens when I buy Pro?
You get a license key. Run board license activate <key> and all Pro features unlock — AI task breakdown, weekly reports, auto changelogs, templates, and analytics. The key is validated offline (no phone home). Use it on all your machines.
Do I need an OpenAI key for board ai?
Yes. You bring your own OpenAI API key. Board Pro gives you the command — you pay OpenAI directly for the tokens (a few cents per prompt). We never see or proxy your API calls.
Can I get a refund?
Yes. 30-day money-back guarantee. If board doesn't improve your workflow, email us and we'll refund you. No questions asked.
