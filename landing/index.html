macOS · Linux · Windows  |  build from source

six commands, all you need 
# initialize in any project
$ bark init

# add tasks
$ bark add "Fix auth bug" -p high -l backend
$ bark add "Write onboarding docs"
$ bark list

# move through workflow
$ bark move fix-auth-bug doing
$ bark done fix-auth-bug

# history, undo, diff — just like git
$ bark log && bark undo && bark diff
