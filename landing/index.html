Task tracking,
the way git does code.

A single binary. No database. No cloud. Works offline.
Like .git but for Kanban boards — committed YAML files you can diff, merge, and grep.

Install in 10 seconds

curl -fsSL https://get.board.io | sh
terminal 
# Initialize in any project
$ board init

# Add tasks — the core six commands you'll use daily
$ board add "Fix auth bug" -p high -l backend
$ board add "Write onboarding docs" -p low
$ board list

# Move tasks through your workflow
$ board move fix-auth-bug doing
$ board done fix-auth-bug

# History, undo, diff — just like git
$ board log
$ board undo
$ board diff

Everything you need. Nothing you don't.

⌨️

Terminal TUI

Interactive Kanban with vim keys, command palette, themes, and query syntax. Never leave your terminal.

board tui
🌐

Web Kanban

Drag-and-drop board, table, calendar, and list views. Live-reloads on file changes. Works in any browser.

board serve --open
🔀

Git-Native

Board files are plain YAML committed to your repo. PRs show card diffs. Merge = sync. No merge conflicts.

board log && board diff HEAD~1
⚡

Powerful CLI

add, move, done, undo, comment, block, snapshot — all from your terminal. Scriptable and pipeable.

🛠️

VS Code + IDE

Open any .board file in VS Code for a full Kanban editor. Neovim floating window. JetBrains browser panel.

🎯

Zero Config

No database, no Docker, no `docker-compose up`. Single binary written in Rust. Works on macOS, Linux, and Windows.
