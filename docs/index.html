Features

Everything you need.
Nothing you don't.

📁

Git-Native

Tasks are YAML files in your repo. Diff them, merge them, grep them. Version control for your project management.

$ git diff main..feature -- *.board
☁️

No Cloud

Works offline. No accounts, no subscriptions, no vendor lock-in. Your data stays in your repo.

$ barkcli list # Works without internet
🖥️

Multi-Interface

CLI, terminal UI, web app, and VS Code extension. Same data, same commands, your choice of interface.

$ barkcli tui # Terminal UI $ barkcli serve # Web app
🔍

Code Context

Automatic code analysis with call graphs, test coverage mapping, and complexity metrics.

$ barkcli context scan
🤖

AI-Ready

MCP server for coding agent integration. Orchestrate task decomposition and agent coordination.

$ barkcli mcp # Start MCP server
📖

Open Source

MIT licensed. Built in Rust. Fast, reliable, and transparent. Contribute or self-host.

$ cargo install barkcli
How It Works

Three commands to start.

1

Initialize

Add barkcli to any project. Creates a .board directory with your configuration.

$ barkcli init
2

Add Tasks

Create cards with priorities, labels, and acceptance criteria.

$ barkcli add "Build login page" -p high -l frontend
3

Work

Move cards across columns. Track progress. Commit changes with your code.

$ barkcli move build-login-page doing
