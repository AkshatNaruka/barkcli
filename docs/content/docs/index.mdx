## What is barkcli?

barkcli is a local-first project management tool. Tasks live as YAML files in your git repository — no cloud, no accounts, no vendor lock-in.

```bash
barkcli init
barkcli create my-project
barkcli my-project add "Implement auth" -p high
barkcli my-project list
```

## Why barkcli?

| Problem | Traditional Tools | barkcli |
|---------|-------------------|---------|
| Cloud dependency | Need internet | Tasks in repo |
| AI can't access tasks | API limits | Direct file access |
| Context switching | Leave IDE | Stay in workflow |
| Vendor lock-in | Can't migrate | Just YAML files |
| Per-seat pricing | $10-15/user/mo | Free forever (MIT) |
