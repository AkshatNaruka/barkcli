# API Reference

The barkcli server exposes a REST API at `http://localhost:4321`.

## Base URL

```
http://localhost:4321
```

## Authentication

When using `--token`, pass the token via:

<Tabs items={["Query Parameter", "Authorization Header"]}>
  <Tab value="Query Parameter">
    ```
    http://localhost:4321/api/boards?token=mysecret
    ```
  </Tab>
  <Tab value="Authorization Header">
    ```
    Authorization: Bearer mysecret
    ```
  </Tab>
</Tabs>

Static assets are always public.

## Board Endpoints

### List Boards

```
GET /api/boards
```

Returns all board names.

**Response:**
```json
{
  "boards": ["my-project", "backend"]
}
```

### Create Board

```
POST /api/boards/create
```

**Request:**
```json
{
  "title": "my-project",
  "description": "Main project board",
  "columns": [
    { "id": "todo", "name": "Todo" },
    { "id": "doing", "name": "Doing" },
    { "id": "done", "name": "Done" }
  ]
}
```

**Response:**
```json
{
  "ok": true,
  "name": "my-project"
}
```

### Delete Board

```
DELETE /api/boards/:name
```

### Get Board

```
GET /api/board?name=my-project
```

Returns YAML content.

### Save Board

```
PUT /api/board?name=my-project
```

**Request:**
```json
{
  "yaml": "columns:\n  - id: todo\n    name: Todo\n"
}
```

## Task Management

### List Tasks

```
GET /api/tasks
```

### Create Task

```
POST /api/tasks
```

**Request:**
```json
{
  "title": "Implement auth",
  "description": "Add JWT authentication",
  "priority": "high",
  "context_files": ["src/auth/handler.ts"]
}
```

### Get Task

```
GET /api/tasks/:task_id
```

### Update Task

```
PUT /api/tasks/:task_id
```

### Delete Task

```
DELETE /api/tasks/:task_id
```

### Claim Task

```
POST /api/tasks/:task_id/claim
```

**Request:**
```json
{
  "agent_id": "claude-code"
}
```

### Complete Task

```
POST /api/tasks/:task_id/complete
```

**Request:**
```json
{
  "result": "Implemented JWT validation",
  "commit_sha": "abc123"
}
```

### Fail Task

```
POST /api/tasks/:task_id/fail
```

**Request:**
```json
{
  "error": "Tests failed"
}
```
