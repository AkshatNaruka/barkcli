# Quick Start

## 1. Initialize Your Project

```bash
cd your-project
barkcli init
```

This creates:
- `.board/` directory for metadata
- `config.json` with default settings
- `.gitignore` for metadata files

## 2. Create a Board

```bash
barkcli create my-project
```

This creates `my-project.board` with default columns.

## 3. Add Your First Card

```bash
barkcli my-project add "Set up CI/CD pipeline" -p high -l devops
```

## 4. List Your Cards

```bash
barkcli my-project list
```

Output:
```
📋 To Do
  [set-up-cicd] Set up CI/CD pipeline (high) #devops

🔄 Doing
  (empty)

✅ Done
  (empty)
```

## 5. Move Cards

```bash
# Start working on it
barkcli my-project move set-up-cicd doing

# Mark as done
barkcli my-project done set-up-cicd
```

## 6. Open the Web UI

```bash
barkcli serve --open
```

This starts the web server and opens the Kanban board in your browser.

## 7. Open the Terminal UI

```bash
barkcli tui
```

This opens the interactive terminal Kanban board.

## Common Workflows

### Daily Standup

```bash
# See what's due today
barkcli today

# See the calendar view
barkcli calendar
```

### Task Breakdown

```bash
# Add a card
barkcli my-project add "Implement user authentication" -p high

# Link sub-tasks
barkcli my-project link implement-user-authentication add-login-form --as parent
barkcli my-project link implement-user-authentication add-session-management --as parent
barkcli my-project link implement-user-authentication add-password-reset --as parent

# See the tree
barkcli my-project tree
```

### Track Progress

```bash
# See status across boards
barkcli status

# Export for reporting
barkcli my-project export json
```
