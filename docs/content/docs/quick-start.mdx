# Quick Start

## 1. Initialize barkcli

```bash
barkcli init
```

This creates:
- `.board/` directory
- `.board/config.json` with default settings
- `.gitignore` entry for `.board/` metadata

## 2. Create a board

```bash
barkcli create my-project
```

Creates `my-project.board` with default columns: `todo`, `doing`, `review`, `done`.

## 3. Add your first task

```bash
barkcli my-project add "Set up CI/CD pipeline" -p high -l devops
```

## 4. List tasks

```bash
barkcli my-project list
```

Output:

```
┌─────────────────────────────────────────────────┐
│ Todo (1)                                        │
├─────────────────────────────────────────────────┤
│ ● set-up-ci-cd-pipeline  high  devops           │
└─────────────────────────────────────────────────┘
```

## 5. Move tasks through your workflow

```bash
barkcli my-project move set-up-ci-cd-pipeline doing
barkcli my-project move set-up-ci-cd-pipeline review
barkcli my-project done set-up-ci-cd-pipeline
```

## 6. Start the web app

```bash
barkcli serve --open
```

Opens `http://localhost:4321` with a visual kanban board.

## 7. Start the terminal UI

```bash
barkcli tui
```

Interactive kanban in your terminal with vim-style navigation.

## Common Workflows

### Daily Standup

```bash
barkcli today
barkcli my-project list -c doing
```

### Task Breakdown

```bash
barkcli my-project add "Implement auth" -p high
barkcli my-project add "Auth: JWT tokens" --as child
barkcli my-project add "Auth: refresh tokens" --as child
barkcli my-project tree
```

### Track Progress

```bash
barkcli my-project status
barkcli my-project export json
```
