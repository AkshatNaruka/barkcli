# barkcli done

Move a card to the done column.

## Usage

```bash
barkcli <board> done <id>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `id` | Card ID |

## Examples

```bash
barkcli my-project done implement-oauth
```

## Output

```
Moved implement-oauth to done
```
