# barkcli show

Display full details of a card.

## Usage

```bash
barkcli <board> show <id>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `id` | Card ID |

## Output

Shows all card fields including:
- Title, description, column, priority
- Labels, assignee, due date
- Effort, area, acceptance criteria
- Checklist items
- Comments
- Links to other cards
- Code context files
- Creation and update timestamps

## Example

```bash
barkcli my-project show implement-oauth
```
