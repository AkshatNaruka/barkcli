# barkcli calendar

Display tasks on a month calendar view.

## Usage

```bash
barkcli calendar [YYYY-MM]
```

## Arguments

| Argument | Description |
|----------|-------------|
| `YYYY-MM` | Month to display (default: current month) |

## Examples

```bash
# Current month
barkcli calendar

# Specific month
barkcli calendar 2025-02
```
