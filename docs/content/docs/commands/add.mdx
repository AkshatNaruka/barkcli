# barkcli add

Add a new card to a board.

## Usage

```bash
barkcli <board> add <title> [options]
```

## Arguments

| Argument | Description |
|----------|-------------|
| `title` | Card title (becomes the card ID) |

## Options

| Flag | Short | Description |
|------|-------|-------------|
| `--column` | `-c` | Column to add to (default: first column) |
| `--priority` | `-p` | Priority: high, medium, low |
| `--description` | `-d` | Card description |
| `--label` | `-l` | Add label (repeatable) |
| `--assignee` | `-a` | Assign to person |
| `--due` | | Due date (YYYY-MM-DD) |
| `--remind` | | Reminder hours before due |
| `--effort` | | Story points or estimate |
| `--area` | | Code area or domain |
| `--ac` | | Acceptance criteria |

## Examples

```bash
# Basic card
barkcli my-project add "Fix login bug"

# Full card
barkcli my-project add "Implement OAuth" \
  --priority high \
  --label backend \
  --label security \
  --assignee alice \
  --due 2025-02-01 \
  --effort 5 \
  --area authentication \
  --ac "Users can log in with Google"

# Short form
barkcli my-project add "Write tests" -p medium -l testing
```

## Card ID

The card ID is auto-generated from the title:
- "Implement OAuth" → `implement-oauth`
- "Fix login bug" → `fix-login-bug`
- "API: Rate limiting" → `api-rate-limiting`

## Output

```
Added card implement-oauth to my-project (todo)
```
