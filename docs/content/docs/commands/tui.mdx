# barkcli tui

Start the interactive terminal UI.

## Usage

```bash
barkcli tui
```

## Tabs

| Tab | Key | Description |
|-----|-----|-------------|
| Board | `1` | Kanban view |
| List | `2` | Flat list |
| Tree | `3` | Hierarchy |
| Agenda | `4` | Today's tasks |
| Reports | `5` | Statistics |
| Code | `6` | Code search |
| Agents | `7` | Agent registry |
| Orchestrate | `8` | Task queue |

## Navigation

| Key | Action |
|-----|--------|
| `h` / `l` | Move between columns |
| `j` / `k` | Move between cards |
| `a` | Add card |
| `e` | Edit card |
| `d` | Delete card |
| `H` / `L` | Move card |
| `/` | Search |
| `:` | Command palette |
| `q` | Quit |
