# barkcli init

Initialize barkcli in your project.

## Usage

```bash
barkcli init
```

## What It Does

1. Creates `.board/` directory
2. Creates `.board/config.json` with default settings
3. Adds `.board/` to `.gitignore` (for metadata only)
4. Installs git hooks (pre-commit, commit-msg)

## Files Created

```
.board/
├── config.json     # Project configuration
└── .gitignore      # Ignores metadata files
```

## Options

| Flag | Description |
|------|-------------|
| `--agent <name>` | Install hooks for specific agent (opencode, claude-code) |

## After Init

```bash
# Create a board
barkcli create my-project

# Add a task
barkcli my-project add "Hello world"

# Start web app
barkcli serve --open
```
