# barkcli code

Search for symbols and files in your codebase.

## Usage

```bash
barkcli <board> code <query>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `query` | Search term (symbol name or file path) |

## Examples

```bash
# Search for a symbol
barkcli my-project code "AuthService"

# Search for a file
barkcli my-project code "src/auth"

# Search for a function
barkcli my-project code "login"
```
