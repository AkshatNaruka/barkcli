# barkcli export

Export a board in YAML or JSON format.

## Usage

```bash
barkcli <board> export [format]
```

## Arguments

| Argument | Description |
|----------|-------------|
| `format` | Export format: yaml (default), json |

## Examples

```bash
# Export as YAML
barkcli my-project export

# Export as JSON
barkcli my-project export json

# Save to file
barkcli my-project export json > backup.json
```
