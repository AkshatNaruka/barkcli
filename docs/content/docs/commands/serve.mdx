# barkcli serve

Start the web app server.

## Usage

```bash
barkcli serve [options]
```

## Options

| Flag | Short | Description |
|------|-------|-------------|
| `--port` | `-p` | Port number (default: 4321) |
| `--host` | | Host address (default: 127.0.0.1) |
| `--token` | | Authentication token |
| `--board` | `-b` | Open specific board |
| `--open` | `-o` | Open browser automatically |
| `--daemon` | `-d` | Run as background daemon |
| `--stop` | | Stop daemon |
| `--status` | | Check daemon status |

## Examples

```bash
# Start server
barkcli serve

# Start and open browser
barkcli serve --open

# Start on custom port
barkcli serve --port 8080

# Start with auth
barkcli serve --token mysecret

# Run as daemon
barkcli serve --daemon

# Stop daemon
barkcli serve --stop
```
