# Command Reference

barkcli commands are organized by category. Each command includes usage, flags, and examples.

## Setup Commands

| Command | Description |
|---------|-------------|
| [`init`](/docs/commands/init) | Set up .board/ directory |
| [`create`](/docs/commands/create) | Create a new board |

## Card Operations

| Command | Description |
|---------|-------------|
| [`add`](/docs/commands/add) | Add a new card |
| [`list`](/docs/commands/list) | List cards in a board |
| [`show`](/docs/commands/show) | Show card details |
| [`move`](/docs/commands/move) | Move a card to a column |
| [`done`](/docs/commands/done) | Mark a card as done |
| [`update`](/docs/commands/update) | Update a card's fields |
| [`remove`](/docs/commands/remove) | Delete a card |

## Board Management

| Command | Description |
|---------|-------------|
| [`boards`](/docs/commands/boards) | List all boards |
| [`switch`](/docs/commands/switch) | Switch default board |
| [`status`](/docs/commands/status) | Show board status |
| [`validate`](/docs/commands/validate) | Validate board files |
| [`doctor`](/docs/commands/doctor) | Auto-fix board issues |

## Links & Hierarchy

| Command | Description |
|---------|-------------|

## Global Flags

| Flag | Description |
|------|-------------|
| `--board`, `-b` | Target a specific board |
| `--help`, `-h` | Show help |
| `--version`, `-V` | Show version |
