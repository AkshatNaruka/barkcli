# barkcli list

List cards in a board with optional filters.

## Usage

```bash
barkcli <board> list [options]
```

## Options

| Flag | Short | Description |
|------|-------|-------------|
| `--column` | `-c` | Filter by column |
| `--priority` | `-p` | Filter by priority |
| `--label` | `-l` | Filter by label |
| `--assignee` | `-a` | Filter by assignee |

## Examples

```bash
# List all cards
barkcli my-project list

# List only doing cards
barkcli my-project list -c doing

# List high-priority cards
barkcli my-project list -p high

# List cards with backend label
barkcli my-project list -l backend

# Combine filters
barkcli my-project list -c doing -p high
```
