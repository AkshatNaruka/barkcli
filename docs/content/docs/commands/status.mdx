# barkcli status

Show a summary of card counts per column across boards.

## Usage

```bash
barkcli status
```

## Output

```
Board Status:

my-project:
  todo:     3
  doing:    2
  review:   1
  done:     5

backend:
  todo:     1
  doing:    0
  review:   0
  done:     2
```
