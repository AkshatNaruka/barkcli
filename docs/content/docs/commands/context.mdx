# barkcli context

Manage code context — links between cards and source files.

## Usage

```bash
barkcli context <command> [options]
```

## Commands

| Command | Description |
|---------|-------------|
| `scan` | Auto-map cards to code |
| `link <card> <path>` | Manually link card to file |
| `unlink <card> <path>` | Remove link |
| `status` | Show coverage and staleness |
| `show <card>` | Show context for a card |
| `sync` | Git-aware refresh |
| `autosync on\|off` | Toggle auto-sync |
| `clear` | Clear all context |

## Scan

```bash
barkcli context scan
```

Fuzzy-matches card titles to code symbols and maps files.

## Manual Link

```bash
barkcli context link implement-auth src/auth/handler.ts
barkcli context link implement-auth "AuthService.login"
```

## Status

```bash
barkcli context status
```

Output:
```
Coverage: 65% (8/12 cards have context)

Card               Files  Status
implement-auth     3      clean
setup-ci           2      changed
write-tests        1      clean
```

## Show

```bash
barkcli context show implement-auth
```

Output:
```
Files:
  src/auth/handler.ts    clean    (abc123)
  src/auth/service.ts    changed  (uncommitted)
  src/auth/types.ts      clean    (abc123)

Symbols: AuthService, login, logout, validate
```

## Sync

```bash
barkcli context sync
```

Updates file statuses based on git state.

## Autosync

```bash
# Enable automatic sync on commit
barkcli context autosync on

# Disable
barkcli context autosync off
```

## Project context file (project_context.md)

`barkcli context` also maintains a living `project_context.md` at the repo root —
a verified central context file generated from tracked work (board, agent
sessions, memory, specs, code map) so AI agent sessions start warm instead of
re-exploring the repository.

| Command | Description |
|---------|-------------|
| `digest` | Regenerate the file from tracked evidence |
| `digest --budget N` | Token budget for the file (default 4000) |
| `digest --polish` | One facts-only LLM pass to rewrite the Brief section |
| `prime` | One-shot bootstrap: scan + generate + wire agent files |
| `wire` | Add `@import` to CLAUDE.md / pointer to AGENTS.md |
| `verify` | Git sync + spec stale-scan + digest in one pass |

```bash
barkcli context prime
barkcli context digest
barkcli context digest --polish
```

Behavior:

- Hand-edited sections are preserved and pinned `manual="true"` automatically.
- Every block carries provenance (`src=`), a staleness score and an updated
  timestamp; the "Verification status" footer flags drifted sections.
- No-op digests write nothing — the rendered file is content-idempotent, so
  `git diff` stays clean.
- `barkcli serve` (including `--daemon`) self-heals the file: board mutations
  made while the server runs are reconciled within seconds.
- When `barkcli session log` ingests an agent session, the digest refreshes
  automatically.
