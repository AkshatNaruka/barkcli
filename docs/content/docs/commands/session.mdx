# barkcli session

Manage captured agent sessions.

## Usage

```bash
barkcli session <command>
```

## Commands

| Command | Description |
|---------|-------------|
| `list` | List all sessions |
| `show <id>` | Show session details |
| `resume <id>` | Resume a session |
| `log <id>` | View session log |

## List Sessions

```bash
barkcli session list
```

Output:
```
Sessions:
  sess-abc123  opencode   2025-01-15  45min  3 files
  sess-def456  claude     2025-01-14  12min  1 file
```

## Show Session

```bash
barkcli session show sess-abc123
```
