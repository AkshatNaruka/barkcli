# barkcli snapshot

Save a named snapshot of the current board state.

## Usage

```bash
barkcli <board> snapshot <label>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `label` | Snapshot label |

## Examples

```bash
barkcli my-project snapshot "pre-release-v1"
barkcli my-project snapshot "after-sprint-1"
```
