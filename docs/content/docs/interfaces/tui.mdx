# Terminal UI

The TUI is a full-screen, keyboard-first kanban built on a token-based design system modeled after clean CLI conventions: borderless data tables, Unicode box-drawing for confirmations, `>`-prefixed status lines, and spinner feedback in the status bar.

## Start

```bash
barkcli tui
```

With one board you land straight in it; with several boards you get a picker first (`j`/`k` to select, `Enter` to open).

Minimum terminal size is **60×12** — below that, barkcli says so instead of drawing a broken layout.

## Tabs

Press `1`–`9`. The active tab is highlighted in the header.

| Tab | Key | Purpose |
|-----|-----|---------|
| Board | `1` | Kanban columns × cards |
| List | `2` | Flat sortable backlog table |
| Tree | `3` | Parent → child hierarchy |
| Agenda | `4` | Overdue, due today, next 7 days |
| Reports | `5` | Sprint burndown + effort stats |
| Code | `6` | Symbol search mapped to cards |
| Agents | `7` | Registered agent identities |
| Orchestrate | `8` | Task queue and cycles |
| History | `9` | History Bundles from your git log |

The status bar always tells you the current mode and the shortcuts that matter right now:

```
 NORMAL │ ↑↓/jk sel · ←→/hl col · Enter detail · a add · e edit …
```

## Board tab

| Key | Action |
|-----|--------|
| `j` / `k`, `↑` / `↓` | Move between cards |
| `h` / `l`, `←` / `→` | Move between columns |
| `Enter` | Card detail |
| `a` | Add card |
| `e` | Edit card |
| `d` | Delete card (confirm with `y`) |
| `H` / `m` | Move card left |
| `L` | Move card right |
| `/` | Filter (`col:` `pri:` `label:` `assignee:` with `Tab` completion) |

Detail overlay: `Esc` close · `e` edit fields · `l` link · `u` unlink.

## List tab

| Key | Action |
|-----|--------|
| `j` / `k` | Navigate |
| `p` / `t` / `e` / `u` | Sort by priority / title / effort / due |
| `a` | Add card |
| `/` | Filter |
| `Enter` | Card detail |

## Other tabs

| Tab | Keys |
|-----|------|
| Agenda, Tree | `j`/`k` navigate, `Enter` detail |
| Reports | Read-only dashboards (`q` to quit) |
| Code | `/` focus search, `j`/`k` navigate results, `Enter` open mapped card — populate with `barkcli context scan` |

## Global keys

| Key | Action |
|-----|--------|
| `1`–`9` | Switch tab |
| `T` | Cycle theme: Dark → Light → Minimal → Dark |
| `:` | Command palette |
| `q` / `Esc` | Quit / close overlay |

## Command palette

`:`, type, `Tab` autocompletes, `Enter` executes.

| Command | Action |
|---------|--------|
| `new` | Start adding a card |
| `move <column-id>` | Move the selected card |
| `filter <text>` | Set (or clear) a filter |
| `sort priority` / `sort title` | Sort the List tab |
| `theme dark` / `theme light` / `theme minimal` | Pick a theme |
| `theme` | Cycle themes |
| `help` | Shortcut help |
| `quit` | Quit |

## Theming

Three built-in themes from one token set (colors, symbols, spacing):

| Theme | Look |
|-------|------|
| `dark` (default) | Deep navy palette, blue accent, Unicode symbols (`▸ ● ✓ █`) |
| `light` | Near-white palette, blue accent, same Unicode symbols |
| `minimal` | Monochrome + ASCII fallbacks (`> * x = -`) — CI-safe and screenshot-friendly |

Switch with `T`, or `:theme <name>` (or plain `:theme` to cycle).

### Colorless terminals

Non-TTY environments (CI, pipes) boot the minimal theme automatically. Force it:

```bash
NO_COLOR=1 barkcli tui           # standard convention
BARKCLI_NO_COLOR=1 barkcli tui   # barkcli-specific flag
```
