# Installation

Choose your preferred installation method:

<Tabs items={["npm", "cargo", "binary"]}>
<Tab value="npm">
```bash
npm install -g barkcli
```
</Tab>

<Tab value="cargo">
```bash
cargo install barkcli
```
</Tab>

<Tab value="binary">
Download the latest binary from GitHub Releases:

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/AkshatNaruka/barkcli/master/install.sh | sh

# Or download manually from:
# https://github.com/AkshatNaruka/barkcli/releases
```
</Tab>
</Tabs>

## Verify Installation

```bash
barkcli --version
# barkcli 0.2.0
```

## Requirements

- **Node.js** 18+ (for npm install)
- **Rust** 1.70+ (for cargo install)
- **Git** 2.30+ (recommended for full functionality)

## Updating

```bash
barkcli update
```
