# Installation

<Tabs items={["npm", "cargo", "binary"]}>
  <Tab value="npm">
    ```bash
    npm install -g barkcli
    ```
  </Tab>
  <Tab value="cargo">
    ```bash
    cargo install barkcli
    ```
  </Tab>
  <Tab value="binary">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/AkshatNaruka/barkcli/main/install.sh | sh
    ```
  </Tab>
</Tabs>

## Verify Installation

```bash
barkcli --version
# barkcli 0.2.0
```

## Requirements

- **Node.js** 18+ (for npm install)
- **Rust** 1.70+ (for cargo install)
- **Git** 2.30+ (for git integration features)

## Update

```bash
barkcli update
```

## Uninstall

```bash
npm uninstall -g barkcli
# or
cargo uninstall barkcli
```
