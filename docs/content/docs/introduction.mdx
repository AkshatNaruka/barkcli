# What is barkcli?

barkcli is a git-native project management tool. Tasks are stored as YAML files in your repository. No cloud. No accounts. Open source. MIT licensed. Built in Rust.

## The Problem

Most project management tools are cloud-first. Your tasks live on someone else's server. You need accounts, subscriptions, and internet access. AI coding agents can't access your tasks without complex API integrations.

## The Solution

barkcli keeps tasks as `.board` YAML files in your repo. They're just like code — you can diff them, merge them, and version control them.

```bash
# Initialize barkcli in your project
barkcli init

# Create a board and add tasks
barkcli create my-project
barkcli my-project add "Implement JWT auth" -p high
barkcli my-project add "Write tests" -p medium

# List tasks
barkcli my-project list

# Move tasks through your workflow
barkcli my-project move implement-jwt-auth doing
barkcli my-project done implement-jwt-auth

# View git history of task changes
barkcli my-project log
```

## How It Works

1. `barkcli init` creates a `.board/` directory in your project
2. Boards are stored as `.board/*.board` YAML files
3. These files are committed to git alongside your code
4. `git diff` shows what tasks changed
5. `git merge` syncs tasks across branches
6. AI agents can read tasks directly from the filesystem

## Core Concepts

| Concept | Description |
|---------|-------------|
| **Project** | Your codebase with a `.board/` directory |
| **Board** | A collection of columns and cards (e.g., "my-project.board") |
| **Card/Task** | A unit of work with title, priority, labels, assignee, due date |
| **Column** | Workflow stage (default: todo, doing, review, done) |
| **Code Context** | Links between cards and source code files |
| **Links** | Relationships between cards (parent, child, related, blocked-by) |

## Interfaces

barkcli provides four interfaces that all share the same YAML data:

| Interface | Command | Description |
|-----------|---------|-------------|
| **CLI** | `barkcli <board> <command>` | Command-line interface |
| **Terminal UI** | `barkcli tui` | Interactive kanban in your terminal |
| **Web App** | `barkcli serve` | Browser-based board at localhost:4321 |
| **VS Code** | Custom editor | Visual editor for .board files |

## Use Cases

- **Solo developers** who want tasks version-controlled with code
- **Small teams** collaborating via git without a server
- **AI-heavy workflows** where coding agents need task context
- **Open source projects** accepting task contributions via PRs
- **Enterprise teams** needing offline-capable project management

## What barkcli is NOT

- Not a replacement for Jira or Linear for large organizations (yet)
- Not a cloud service — everything runs locally
- Not a real-time collaboration tool — git is the sync mechanism
- Not a project management tool for non-technical users
