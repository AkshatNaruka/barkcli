# Sprints

Sprints provide time-boxed planning with velocity tracking.

## Commands

```bash
# Start a sprint
barkcli sprint start <name>

# End current sprint
barkcli sprint end

# List sprints
barkcli sprint list

# View sprint details
barkcli sprint show <name>
```

## How It Works

1. **Start sprint** — Tags current `todo` cards with `sprint:<name>` label
2. **Work on tasks** — Move cards through workflow
3. **End sprint** — Moves remaining cards to backlog, calculates velocity

## Sprint Data

Sprints are stored in `.board/sprints/<board>.json`:

```json
{
  "sprints": [
    {
      "name": "sprint-1",
      "started_at": "2025-01-15T09:00:00Z",
      "ended_at": "2025-01-29T17:00:00Z",
      "cards_total": 12,
      "cards_completed": 10,
      "velocity": 10
    }
  ]
}
```

## Velocity Tracking

```bash
# View velocity
barkcli stats

# Report with sprint data
barkcli report --sprint sprint-1
```

## Sprint Workflow

```bash
# 1. Plan sprint
barkcli sprint start sprint-1

# 2. Add sprint tasks
barkcli my-project add "Feature A" -l sprint-1
barkcli my-project add "Feature B" -l sprint-1
barkcli my-project add "Bug Fix C" -l sprint-1

# 3. Work on tasks
barkcli my-project move feature-a doing
barkcli my-project done feature-a

# 4. End sprint
barkcli sprint end

# 5. View results
barkcli sprint list
```

## API Access

```bash
# List sprints
curl http://localhost:4321/api/sprints

# Start sprint
curl -X POST http://localhost:4321/api/sprints \
  -H "Content-Type: application/json" \
  -d '{"name": "sprint-2"}'

# End sprint
curl -X POST http://localhost:4321/api/sprints/end
```
