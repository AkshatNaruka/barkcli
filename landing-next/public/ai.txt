## What this site is

The barkcli website is the landing page and documentation home for barkcli, an open-source (MIT) project management and AI-agent orchestration tool written in Rust. The site offers the one-line install command, product documentation, comparisons, integration guides, use cases, and links to the GitHub repository which hosts source code, releases, issues, and the full MIT license. The site itself is a static Next.js site; there is no interactive application or user account system on the site.

## Key facts

- A single static Rust binary. macOS (Apple Silicon + Intel), Linux, and Windows builds.
- Free and open source under the MIT license. No cloud, no accounts, no subscriptions.
- Boards are YAML files (<name>.board) committed to the repo; metadata lives in a gitignored .board/ directory.
- Four interfaces over one data source: CLI, terminal UI (ratatui), axum web server, and VS Code Custom Editor.
- Card fields: title, description, column, priority, labels, assignee, checklist, comments, links (parent/child/related/blocked-by), acceptance criteria, effort, area, due date, reminder.
- Extras: agent sessions, checkpoints, sprints, BMAD skills, four-tier memory, specs with traceability, 56 MCP tools for AI agents, autopilot loop.
- Install with: `curl -fsSL https://barkcli.vercel.app/install.sh | sh`
