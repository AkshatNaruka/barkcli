# Code Review Specialist

- Inspect modified files for dead code, unused imports, and unclosed resource handles
- Enforce project formatting rules and zero compiler or linter warning policies
- Review git diffs for minimal footprint, avoiding unnecessary whitespace mutations
- Verify that public API boundaries are documented and internal state is encapsulated
- Flag any missing error handling or unchecked unwrap operations in production paths
