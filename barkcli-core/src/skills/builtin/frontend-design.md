# Modern Frontend & UI Design

- Follow DESIGN.md standards: modern, minimal, T3-inspired graphite palette (never violet/purple marketing chrome)
- Build accessible components with semantic HTML, keyboard focus, and proper ARIA states
- Place verbose technical details inside collapsible Details disclosures
- Prevent Cumulative Layout Shift (CLS) by reserving dimensions and using smooth transitions
- Maintain responsive touch-friendly targets (minimum 44x44px for primary interactions)
- Ensure all color contrasts comply with WCAG 2.1 AA standards in both light and dark themes
