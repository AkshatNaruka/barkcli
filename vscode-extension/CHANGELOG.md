# Changelog

## 0.1.0 — Initial Release

- Kanban board editor for `.board` files
- Drag-and-drop card movement between columns
- Card CRUD: create, edit, delete with modal forms
- Priority coloring (high/medium/low) with left border indicators
- Label pills displayed on cards
- Context menu with Edit, Move Left/Right, Delete actions
- VS Code theme-aware styling
- Auto-save on card changes via YAML serialization
- Support for all card fields: title, description, assignee, labels, priority, due date
